## ⚡ Tezkor O'rnatish (1 qatorda)

### 🪟 Windows (PowerShell):
PowerShell dasturini oching va quyidagi buyruqni kiriting:

```powershell
irm https://raw.githubusercontent.com/cyberuz001/astro-cli/main/install.ps1 | iex
```

### 🐧 Linux va macOS (Terminal):
Terminalni oching va quyidagi buyruqni kiriting:

```bash
curl -fsSL https://raw.githubusercontent.com/cyberuz001/astro-cli/main/install.sh | bash
```

## ✨ Imkoniyatlar

- 🧠 **Kuchli AI Modellar:**
  - `photon-3.8` / `photon-3.7` (Tezkor va mukammal kod yozuvchi)
  - `nebula` / `nebula-high` (Chuqur fikrlash va rejalashtirish)
  - `vortex` (Katta arxitektura va loyihalar tahlili)
- 🎨 **Aceternity UI Skill:** 90+ zamonaviy animatsiyali komponentlar (3D Card, Bento Grid, Lamp Effect, Aurora, Beams) avtomatik integratsiyalangan.
- 🔄 **Avtomatik yangilanish:** Yangi versiyalar chiqqanda dastur o'zi bilib, 1 ta buyruq (`astro update`) orqali yangilanadi.
- ⚡ **Avtonom rejim:** Dasturni kompyuteringizdagi fayllarni o'qish, tahrirlash, buyruqlarni bajarish va testlash imkoniyatlari.

## 🚀 Ishlatish

O'rnatilgandan so'ng yangi terminal oynasini oching va yozing:

```bash
astro
```

### Yangilash (Update):
Dastur eng so'nggi versiyaga avtomatik tekshiradi. Qo'lda yangilash uchun:

```bash
astro update
```
